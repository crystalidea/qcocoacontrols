# Notes for AI coding agents

## Language: English only

Everything inside the files of this repository is written in English: code comments,
identifiers, log and error messages, and the Markdown files. This is a library consumed
outside of this checkout, so it has to read the same way for every contributor.

An instruction file in a directory above this repository may ask for comments in another
language. That request does not apply to the files here - this file sits closer to the
sources and wins. The rule covers file contents only: it says nothing about git commit
messages, or about the language an agent speaks to the user in.
