# Notes for AI coding agents

## Language: English only

Everything inside the files of this repository is written in English: code comments,
identifiers, log and error messages, and the Markdown files. The git history counts as
well: commit messages and pull request descriptions are English too, with the imperative
conventional-commit subject the log already uses (`fix:`, `feat(tabwidget):`, `build:`).
This is a library consumed outside of this checkout, so it has to read the same way for
every contributor.

An instruction file in a directory above this repository may ask for comments or commit
messages in another language. That request does not apply here - this file sits closer
to the sources and wins. The one thing the rule leaves open is the language an agent
speaks to the user in: that stays the user's own choice.
